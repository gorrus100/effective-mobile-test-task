# effective-mobile-test-task
Решение DevOps тестового задания для Effective-Mobile. Развертывание приложения и Nginx в качестве reverse-proxy в Docker-контейнерах с помощью Docker Compose.


# План реализации
- разработка backend + запуск в контейнере
- запуск nginx в контейнере, проверка проксирования
- составление docker compose
- развернуть через vagrant + ansible, для имитации деплоя на удалённый сервер
- Readme 

# Описание backend
- сервер на python с endpoint -> / по которому отвечает сервер 
- порт для сервера берётся из файла .env, при отсутствии переменной вывод ошибки о необходимости её установления. порт задаётся произвольный, но по заданию 8080
- для примера файла .env создан .env.example 
- использование сторонних модулей, с определением их версии
- Dockerfile 
    - multistage
    - использованы практики по облегчению образа на выходе
    - применяется healthcheck для использования в docker compose
    - запуск от не root пользователя
    - более детальные действия составления Dockerfile описаны комментариями в нём
